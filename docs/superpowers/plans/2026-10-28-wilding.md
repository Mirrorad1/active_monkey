# Wilding Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A playable desktop evolutionary sandbox matching the approved Terrarium mockup, with measured simulation data and a 1,000-creature benchmark.

**Architecture:** A standalone C# simulation owns terrain, resource regeneration, creatures, mutation, lineage, snapshots and deterministic random state. Godot owns the 3D terrain, batched pixel sprites, camera, edit tools and charts. Existing Python ecology remains a reference; this initial game is a new, explicitly simplified model, not a parity-verified port.

**Tech Stack:** Godot .NET, C# / .NET 8, dependency-free console verification harness.

**Spec:** Approved in conversation: Terrarium world-first layout; stepped island, small grazer/hunter sprites, whole-population observation, editable forest/water/refuges, pause and speed, inherited-trait distributions and trends. Desktop first. Local save/load and fork snapshots.

## Global Constraints

- Work under `wilding/`; existing modified files and FROZEN paths are out of scope.
- Actual simulation samples feed the charts; no mock data or implied research discovery.
- All traits cost energy. Births follow local energy and maturity, never a global fitness ranking.
- Fixed ticks, explicit RNG state, bounded histories, local neighbor searches; camera does not change simulation rules.
- Terrain and sprites render in batches. Do not promise frame rates before measurement.
- Genotype, survivor traits and newborn traits are explicitly distinct in telemetry.
- User authorized direct implementation. Work in the current checkout; avoid unrelated branch/state changes.

## Review Focus

- Save/load and fork must preserve RNG and future trajectories, including terrain edits.
- Water edits must not strand creatures indefinitely; no placement on impassable terrain.
- Empty populations must render empty chart states and never fabricate zero-valued observations.
- Birth/mutation cannot create free energy; parameters remain finite and bounded.
- Population caps are instrument limits, visibly reported; no silent ecological interpretation of cap saturation.
